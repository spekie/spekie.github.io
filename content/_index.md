# About Me

My name is German, but I am mostly known as Spekie on the internet. I am from Saint Petersburg, Russia.

My primary interests are in computer architecture, cybersecurity, system administration, and digital privacy.

I have many computers, with the primary operating systems running on them being Unix-like.

Linux distributions I know well: [NixOS](https://nixos.org), [Gentoo Linux](https://www.gentoo.org), [Void Linux](https://voidlinux.org), [Arch Linux](https://archlinux.org), [Debian](https://www.debian.org), and [Fedora](https://fedoraproject.org).

I am also familiar with the BSD derivatives such as [OpenBSD](https://www.openbsd.org), [NetBSD](https://www.netbsd.org), and [FreeBSD](https://www.freebsd.org).

In programming I usually code in C or C++ but I am currently learning more programming languages.

My programming projects can be found on [GitHub](https://github.com/spekie). I have accounts on other git forges but I primarily use GitHub.

As for human languages, I know Russian, English, German, Romanian, Polish, and currently learning Japanese.
